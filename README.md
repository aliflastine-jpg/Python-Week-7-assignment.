
# PLP Python Week 7 Assignment

This repository contains my Python file handling and CSV report builder assignment.

## Project Files

- my_notes.py - Writes, appends, reads and counts notes.
- my_notes.txt - Stores the four notes.
- report_builder.py - Reads CSV data and generates a learner report.
- hubs.csv - Contains learner names, hubs and scores.
- report.txt - Contains the generated learner report.

## What happens if "a" is changed to "w"?

If I change append mode ("a") to write mode ("w"), Python will erase the existing contents of the file before writing. The previous notes will be lost, and only the new note will remain.
